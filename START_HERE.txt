WALDEN TURTLE (React + ArcGIS version): how to run the map

You need two free programs: Python 3.10+ (python.org) and Node.js 20+ (nodejs.org).

STEP 1. Build the data (Python). Do this once, and again whenever you change a rule or a setting in build_data.py.
    pip install numpy pyproj pillow
    python3 build_data.py
  This writes the map's data files into app/public/data/ and the fonts into app/public/fonts/.

STEP 2. Run the app (Node). In a terminal:
    cd app
    npm install          (first time only; downloads React and the ArcGIS SDK, about 1 minute)
    npm run dev          (starts the map; open the address it prints, usually http://localhost:5173)

TO PUBLISH IT:
    npm run build        (makes the folder app/dist)
  Upload everything inside app/dist to any web host. Note: unlike the old single-file version, dist cannot be
  opened by double-clicking index.html. A browser will not load the data files from a plain file. Use a web host,
  or run "npm run preview" to test it on your own computer.

The map needs an internet connection: it fetches some ArcGIS support files from Esri when it opens.

The full guide (what each file does, what to change, fixing problems) is in the document
"Walden Turtle, React Version: Guide to the Code".
